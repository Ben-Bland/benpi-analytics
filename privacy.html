Privacy Policy

benpi analytics. Last updated 29 August 2026.

Who this covers

benpi analytics is a private script used by one person: its author, who is also the owner of the YouTube channel it reads. It has no other users. It does not offer accounts, and no one else can authorize it or use it.

What it accesses

When its author signs in with Google, the application requests read-only access to two things belonging to that same account:

  • YouTube Data API (read only). The list of videos published on the author's channel, with titles and publication times.
  • YouTube Analytics API (read only). Aggregate performance statistics for those videos: views, watch time, average view duration, and audience retention.

Both scopes are read only. The application cannot upload, edit, delete, or change anything on the account.

What it does with the data

Statistics are written to a private database used only by the author, to compare how videos perform over time. The data is never sold, published, shared with third parties, or used for advertising, and it is not used to train any model.

Where the data is stored

On a computer in the author's home and in the author's own private Notion workspace. Google credentials are stored only on that computer and are never transmitted anywhere except to Google.

Other people's data

The application never receives information about individual viewers. YouTube provides only aggregate, anonymous figures such as totals and averages.

Revoking access

Access can be withdrawn at any time from the Google Account permissions page at myaccount.google.com/permissions. Doing so immediately stops all further access.

Google API Services User Data Policy

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
